# FP&A Excel Model

## 📌 Project Overview

This is a driver-based FP&A model built to forecast revenue and costs, perform variance analysis, and produce executive-ready summaries.

---

## 🧠 Business Context

Used to simulate a monthly financial planning cycle including:
- Revenue forecasting  
- Operating expense analysis  
- Variance vs actuals  
- Scenario & sensitivity tables

---

## 📊 Key Features

- `Assumptions` tab for inputs & drivers  
- `Forecast` tab with formulas and linked sheets  
- `Variance` dashboard for actual vs forecast  
- Scenario analysis

---

## 📈 Insights

- Key drivers impacting revenue  
- Cost behavior over forecast horizon  
- Highlighted risks and opportunities
