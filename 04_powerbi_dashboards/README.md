# Power BI Dashboards

## 📌 Project Overview

This folder contains Power BI dashboards built to visualize key financial and business metrics. Includes interactive visuals for revenue, margins, customer metrics, and portfolio performance.

---

## 📊 Dashboards

Each report answers specific business questions, such as:
- Trend analysis & KPIs
- Segment performance
- Risk heatmaps
- Trend decomposition

---

## 🛠 Tools Used

- Power BI Desktop  
- DAX measures  
- Data modeling
