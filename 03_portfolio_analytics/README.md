# Portfolio Analytics

## 💡 Project Summary

This project analyzes the returns and risk of a hypothetical investment portfolio using Python. It demonstrates time-series analytics, performance metrics, and portfolio comparisons.

---

## 🔍 Questions Explored

1. Asset returns over time  
2. Volatility and rolling Sharpe ratio  
3. Maximum drawdown analysis  
4. Correlation between assets  
5. Risk attribution

---

## 🛠 Tools Used

- Python (pandas, numpy, matplotlib/seaborn)  
- Jupyter Notebook (.ipynb)

---

## 📊 Key Results

- Risk/return comparison chart  
- Portfolio performance over multiple periods  
- Interpretation of Sharpe & drawdown measures
